# 📋 Cyclea - Conditions Générales d'Utilisation (CGU)

Ce dépôt contient les documents légaux officiels et les Conditions Générales d'Utilisation (CGU) de l'application mobile **Cyclea**.

## 📱 À propos de l'application

**Cyclea** est une application mobile de suivi du cycle menstruel, de la fertilité et de la grossesse. Elle permet aux utilisatrices de suivre leurs symptômes, d'anticiper leurs cycles et de gérer leur grossesse en toute simplicité.
